# AI エージェントにブラウザを操作させるとき

Claude Code（Claude in Chrome）や Codex などの AI エージェントにブラウザを操作させるときも、2password でログイン画面に入力できます。エージェントはログイン欄と 2password の候補をクリックするだけです。パスワードは拡張機能と 2password アプリの間で受け渡し、エージェントには渡しません。

## しくみ

```text
エージェント ──クリック──▶ ログイン欄 → 2password の候補（「2password で入力: 項目名（ユーザー名）」）
                                   │
                                   ▼
                      2password アプリ：利用者が「許可する」を押す
                                   │
                                   ▼
          拡張機能が、項目の URL に一致するページにだけ入力する
```

| 守ること | 内容 |
|---|---|
| **パスワードをエージェントに渡さない** | 入力は拡張機能が行います。候補の名前（アクセシビリティツリー）にも、入力後の画面にもパスワードは出ません。エージェントが画面で確かめられるのは「2password で入力しました」というお知らせだけです |
| **入力のたびに人が許可する** | **⚙ 設定 → ブラウザ拡張機能 → 入力のたびに確認する** をオンにすると、エージェントが項目を選ぶたびに、アプリの画面で許可を求めます。許可は 2 分間だけ有効です（続く 2 段階認証のコードの入力にも使います） |
| **偽サイトには入力しない** | ページに書かれた指示でエージェントがだまされても、項目の URL と一致しないページにはパスワードもコードも返しません。似た名前のサイトでは警告を出します |
| **連続した要求でロックする** | 短い時間に要求が続いたら、2password をロックします |

許可されるまで、拡張機能は「2password アプリで許可してください」と表示して待ちます。許可されると、候補を選び直さなくても入力します。拒否したときは入力せず、そのことを表示します。

## 準備

1. いつもの Chrome に 2password の拡張機能を入れ、アプリと接続します（[docs/EXTENSION.md](EXTENSION.md)）。Claude in Chrome や Codex の拡張機能は、この同じ Chrome を操作します。
2. アプリの **⚙ 設定 → ブラウザ拡張機能 → 入力のたびに確認する** をオンにします（おすすめ）。
3. エージェントに使い方を伝えます。下の文を `CLAUDE.md`（Claude Code）や `AGENTS.md`（Codex）に書いておくと、毎回説明しなくて済みます。

```markdown
## ブラウザでのログイン

- ログインが必要なときは、ユーザー名かパスワードの欄をクリックし、
  「2password で入力: 項目名（ユーザー名）」という候補をクリックする。キーボードなら ↓ と Enter で選べる
- 「2password アプリで許可してください」と出たら、利用者が許可するまで待つ（最大 2 分）
- 「2password で入力しました」と出たら、ログインのボタンを押す
- パスワードを自分で入力したり、入力欄の値を読み取ったりしない
- 候補が出ない・「拒否されました」と出たときは、操作を止めて利用者に知らせる
```

## エージェントからの操作

| 操作 | 方法 |
|---|---|
| 候補を出す | ログイン欄（ユーザー名・パスワード・認証コード）をクリックします。閉じたあとは、欄で ↓ を押すと開き直します |
| 候補を選ぶ | 候補をクリックするか、↓・↑ で移って Enter を押します（Enter でフォームは送信しません） |
| 候補を見つける | 候補には「2password で入力: 項目名（ユーザー名）」という名前が付いています。スクリーンショットのほか、アクセシビリティツリーを読むツール（`find`、`read_page` など）でも見つかります |
| 結果を確かめる | 右上のお知らせ（「2password で入力しました」「2password アプリで拒否されました」など）を見ます |

ページのスクリプトが作ったクリックやキー入力では、候補は選ばれません。エージェントの操作は、ブラウザの DevTools プロトコルを通るため、人の操作と同じように扱われます。

## 知っておいてほしい限界

- エージェントがページの中でスクリプトを実行できる場合（Claude in Chrome の `javascript_tool` など）、入力したあとのパスワード欄の値は読めてしまいます。これはブラウザの作りによるもので、拡張機能では防げません。大事なアカウントでは、エージェントのスクリプト実行を許可しないか、ログインだけは自分で行ってください。
- **入力のたびに確認する** をオフにすると、一度許可した「項目とサイトの組み合わせ」は、確認なしで入力します。エージェントに任せる間はオンにしておくことをおすすめします。
- エージェントによっては、自分の決まりにより、ログインの操作を断ったり、利用者に任せたりすることがあります。
- 2 段階認証のコードは、項目を選んでログインした直後（2 分以内）に、同じサイトで認証コードの欄が出たときだけ自動で入力します。
