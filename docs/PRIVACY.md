# プライバシーポリシー（2password / 2password ブラウザ拡張機能）

最終更新日：2026年11月14日

2password と 2password ブラウザ拡張機能（以下「本ソフトウェア」）は、AIGYM株式会社が Toramon Shield プロジェクトとして公開しているオープンソースソフトウェアです。

## 収集する情報

**開発元は、利用者の情報を一切収集しません。** 本ソフトウェアには、利用状況の計測、広告、開発元のサーバーへの通信は含まれていません。

## 本ソフトウェアが扱う情報

本ソフトウェアは、利用者自身のために次の情報を扱います。

| 情報 | 保存場所 | 用途 |
|---|---|---|
| ログイン情報（サイトのアドレス、ユーザー名、パスワード、メモ） | 利用者のパソコンで暗号化し、利用者が選んだ保存先（同期フォルダまたは利用者自身の Google Drive）に暗号文として保存 | ログイン情報の保管と入力 |
| パスキー（サイト名、利用者の識別子、秘密鍵） | ログイン情報と同じく、暗号文として保存。秘密鍵はデスクトップアプリの外に出さない | パスキーでのログイン |
| Secret Key、Google のアクセストークン | 利用者のパソコンの OS キーチェーン | 保管庫の復号、利用者自身の Google Drive へのアクセス |
| 表示中のページのアドレス（オリジン） | 保存しない | そのサイトに一致するログイン情報を探すため、同じパソコンのデスクトップアプリに渡す |
| 自動入力を許可した「項目とサイトの組み合わせ」 | 利用者のパソコンの設定フォルダ。ハッシュ値だけを保存し、サイト名は保存しない | 初めて使うサイトでの確認を、2 回目から省くため |
| 拡張機能からの要求の履歴（時刻、サイトのホスト名、項目のタイトル） | デスクトップアプリのメモリ（最大 50 件）。ロックすると消える。ディスクには保存しない | 身に覚えのない要求がないか、利用者が確かめるため |
| 送信されたログイン情報（保存の確認が終わるまで） | ブラウザのメモリ（最長 2 分）。ディスクには保存しない | 「保存しますか？」の確認 |

## 第三者への提供

本ソフトウェアは、利用者の情報を第三者に販売・提供しません。

ブラウザ拡張機能が通信する相手は、同じパソコンで動く 2password デスクトップアプリだけです。デスクトップアプリは、利用者が Google Drive を保存先に選んだ場合に限り、利用者自身の Google Drive に暗号文を保存します。Google に渡るのは暗号文とファイル名・サイズ・更新時刻だけで、開発元も Google も中身を読めません。

## 利用者による管理

保存したデータは、デスクトップアプリからいつでも削除できます。拡張機能とアプリをアンインストールすれば、本ソフトウェアによる処理は止まります。
