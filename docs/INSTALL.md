# 2password のインストールと使い方（一般の方向け）

プログラミングの知識は要りません。ダブルクリックでインストールできます。

インストーラーは [リリースページ](https://github.com/toramon-shield/2password/releases/latest) からダウンロードできます。

## Windows

1. `2password-windows-x64-setup.exe` をダブルクリックします。
2. 「Windows によって PC が保護されました」と表示された場合は、**詳細情報** → **実行** を押します。
   - まだ有料の電子署名をしていないため表示されます。配布元が信頼できる場合だけ実行してください。
3. 画面の案内に従って **インストール** を押します（管理者権限は不要です）。
4. スタートメニューまたはデスクトップの **2password** から起動します。

> Windows 10 の古い環境では、画面表示に必要な部品（WebView2）が自動でダウンロードされることがあります。インターネットにつないだ状態でインストールしてください。

## Mac

1. `2password-macos-universal.dmg` をダブルクリックします。
2. 開いた画面で、**2password** のアイコンを **Applications（アプリケーション）** フォルダにドラッグします。
3. 初回だけ、アプリケーションフォルダの 2password を **右クリック（control + クリック）→ 開く** → **開く** を押します。
   - 「開発元を検証できません」と表示されるのは、Apple の公証（有料の開発者登録が必要）をまだ受けていないためです。
   - それでも開けない場合は、**システム設定 → プライバシーとセキュリティ** の下の方にある **このまま開く** を押します。
4. 初回、キーチェーンへのアクセス確認が出たら **常に許可** を選びます（Secret Key を Mac のキーチェーンに保存するためです）。

## はじめて使うとき

1. **新しく始める** を押します。
2. 保存先を選びます。
   - **Google Drive（おすすめ）**：ブラウザが開くので、Google アカウントでログインし、「このアプリで使用するファイルのみ」の権限を許可します。
   - **同期フォルダ**：Google ドライブ for デスクトップのフォルダなどを指定します。
   - 「この版には Google ログインの設定が含まれていません」と表示される版では、**同期フォルダ** を選んでください。
3. **アカウントパスワード** を決めます。単語を4〜5個つなげた、長くて自分だけが覚えられるものにしてください。強度のバーが緑になれば使えます。
4. **Secret Key** が表示されます。**Emergency Kit を開いて印刷する** を押し、印刷して施錠できる場所に保管してください。
   - 印刷したら、書類フォルダの `2password-emergency-kit.html` は削除してください。
   - アカウントパスワードは Emergency Kit には書かず、別に保管してください。

## 2台目のパソコンで使うとき

1. **既存の保管庫に参加** を押します。
2. 1台目と同じ保存先を選び、Emergency Kit の **Secret Key** とアカウントパスワードを入力します。

## 毎日の使い方

| やりたいこと | 操作 |
|---|---|
| パスワードを登録 | **＋ 追加**。パスワード欄を空にすると、強いパスワードを自動で作ります |
| パスワードを使う | 項目を選んで **コピー**。30秒後にクリップボードから自動で消えます |
| パスワードを見る | **表示**（20秒後に自動で隠れます） |
| 他の端末の変更を取り込む | 右上の **⟳** |
| 席を離れる | 右上の **🔒**。5分間操作がないと自動でロックされます |

## ブラウザで自動入力する

Chrome / Edge / Brave の拡張機能を入れると、ログイン画面で候補を選んで入力したり、ログイン後に保存したりできます。入れ方は [ブラウザ拡張機能の使い方](EXTENSION.md) を見てください。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「解除できませんでした」 | アカウントパスワードを確認してください。大文字・小文字も区別されます |
| Google のログイン画面で「このアプリは確認されていません」 | 配布元が信頼できる場合は **続行** を押します |
| 1週間ほどで Google のログインを求められる | 配布しているアプリが「テスト中」の設定のためです。配布元に連絡してください |
| パスワードも Emergency Kit も失くした | **誰にも復旧できません**（2password の作者にも Google にも、中身は読めないためです） |

> ⚠ 2password は 1Password の安全設計を学ぶために作られたアプリで、第三者のセキュリティ監査は受けていません。大切な情報を保存する前に、この点を理解したうえで使ってください。
