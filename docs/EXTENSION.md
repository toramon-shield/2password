# ブラウザ拡張機能（Chrome / Edge / Brave）

2password のブラウザ拡張機能を入れると、次のことができます。

| できること | 動き |
|---|---|
| **ログイン画面で呼び出す** | ID やパスワードの欄をクリックすると、そのサイトの項目が候補として出ます。選ぶと入力されます |
| **ログイン後に保存する** | 新しいログイン情報を送信すると、「保存しますか？」と確認します |
| **パスワードの変更に追従する** | 保存済みのサイトで違うパスワードを使うと、「更新しますか？」と確認します |
| **強いパスワードを作る** | 新規登録の画面で、パスワードを自動で作って入力します |
| **偽サイトを避ける** | 保存したときと違うドメインのページには、候補を出しません |

拡張機能だけでは動きません。**2password デスクトップアプリ（0.2.0 以降）が起動していて、ロックが解除されている**必要があります。

## 使い始める

### 1. 拡張機能を入れる

**A. Chrome ウェブストアから入れる**（審査が通ったあとに使えます）

ストアのページで **Chrome に追加** を押します。

**B. 開発版を読み込む**（いますぐ使えます）

1. このリポジトリを ZIP でダウンロードして展開します（または `git clone` します）。
2. Chrome で `chrome://extensions` を開きます（Edge は `edge://extensions`）。
3. 右上の **デベロッパー モード** をオンにします。
4. **パッケージ化されていない拡張機能を読み込む** を押し、展開したフォルダの中の **`extension` フォルダ** を選びます。
5. 一覧に **2password** が出れば完了です。ツールバーのパズルのアイコンから、ピン留めしておくと便利です。

> 開発版の ID は `fikflmlcdfanbjpplbnhlhnhbmefokoe` に固定されています。違う ID が表示される場合は、下の「うまくいかないとき」を見てください。

### 2. アプリと接続する

1. 2password デスクトップアプリを起動して、ロックを解除します。
2. 右上の **⚙（設定）** → **ブラウザ拡張機能** → **ブラウザと接続する** を押します。
3. ブラウザを再起動します。

接続は、いまの利用者の分だけ登録されます（管理者権限は使いません）。アプリを更新したり、別の場所に移したりしたあとは、もう一度 **ブラウザと接続する** を押してください。

### 3. 使ってみる

- **保存する**：いつもどおりサイトにログインします。次の画面の右上に「ログイン情報を保存しますか？」と出たら **保存する** を押します。
- **入力する**：次にそのサイトのログイン画面を開き、ID かパスワードの欄をクリックします。候補を選ぶと入力されます。
- **ツールバーから入力する**：ツールバーの 2password のアイコンを押すと、そのサイトの項目が出ます。

アプリで手動で登録した項目を候補に出すには、項目の **URL** 欄にサイトのアドレス（例：`https://example.com`）を入れてください。

## 1Password などから移行する

アプリの **⚙（設定）** → **他のツールから取り込む** → **CSV を選んで取り込む** で、ほかのツールが書き出した CSV を読み込めます。

| ツール | 書き出し方 |
|---|---|
| 1Password | デスクトップアプリの **ファイル → エクスポート** で、形式に **CSV** を選ぶ |
| Chrome | `chrome://password-manager/settings` → **パスワードをエクスポート** |
| Edge | **設定 → パスワード → … → パスワードのエクスポート** |
| Bitwarden | **ツール → 保管庫のエクスポート** で、形式に **.csv** を選ぶ |

タイトル・URL・ユーザー名・パスワード・メモを取り込みます。ワンタイムパスワード（TOTP）、クレジットカード、添付ファイルは取り込みません。

> [!CAUTION]
> 書き出した CSV には、すべてのパスワードが平文で入っています。取り込みを確かめたら、すぐに削除してください（ごみ箱も空にします）。

コマンドラインでは `2pw import export.csv` で取り込めます。

## しくみと安全性

```
ページ（content.js） ⇄ 拡張機能（background.js） ⇄ 2password --native-host ⇄ デスクトップアプリ
                                          Native Messaging          127.0.0.1 + 合言葉
```

- **鍵は拡張機能に渡しません**。Secret Key、アカウントパスワード、保管庫の鍵は、デスクトップアプリの中だけにあります。拡張機能からロックを解除することはできません。
- **パスワードは、選んだ項目の分だけ渡します**。候補の一覧にはタイトルとユーザー名しか含まれません。
- **サイトの照合はアプリ側で行います**。「どのサイトか」は、ページの申告ではなくブラウザが拡張機能に教える情報を使います。項目の URL と、スキーム（https）・ポート・ホスト名が一致するページにだけ返します。サブドメインは、保存したホストの下位だけ一致します（`example.com` で保存 → `login.example.com` に一致。逆は一致しません）。
- **自動では入力しません**。入力は、利用者が候補をクリックしたときだけです。
- **呼び出せる拡張機能を限定しています**。ブラウザは、アプリが登録した ID の拡張機能にだけ、アプリの呼び出しを許します。
- **外部には何も送りません**。拡張機能が通信する相手は、同じパソコンのデスクトップアプリだけです。

### 知っておいてほしい限界

- 2password は学習・検証用のプロジェクトで、拡張機能も第三者の監査を受けていません。
- ページの中に埋め込まれた別サイトの枠（iframe）のログイン欄には対応していません。
- 入力したあとの値は、そのページのスクリプトから読めます（どのパスワード管理ツールでも同じです）。信頼できないサイトでは候補を選ばないでください。
- 保存の確認は、ログインが成功したかどうかを判定しません。間違ったパスワードを送った場合は **今回はしない** を押してください。
- 保存待ちのログイン情報は、確認が終わるまでブラウザのメモリ（`chrome.storage.session`）に最長 2 分だけ置かれます。ディスクには書きません。
- 同じパソコンに同じ利用者として入り込んだ不正なプログラムからは守れません（デスクトップアプリ本体と同じ前提です）。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| ポップアップに「アプリと接続できていません」と出る | アプリの **設定 → ブラウザと接続する** を押し、ブラウザを再起動します |
| 「アプリが起動していません」と出る | デスクトップアプリを起動します |
| 開発版の ID が `fikflm…` と違う | ポップアップに表示される ID を、アプリの **設定 → 拡張機能の ID を指定する** に入力してから **ブラウザと接続する** を押します |
| 候補が出ない | 項目の URL がそのサイトのアドレスになっているか確かめます。`http://` のページには、`http://` で保存した項目しか出ません |
| ページを開いたままで拡張機能を入れた | ページを再読み込みします |

## Chrome ウェブストアへの提出（メンテナー向け）

```bash
python scripts/package-extension.py     # dist/2password-extension-<version>.zip を作る
```

1. [デベロッパー ダッシュボード](https://chrome.google.com/webstore/devconsole) で **新しいアイテム** を押し、ZIP をアップロードします。
2. 掲載情報を入力します。下の文面を使えます。
3. 審査に提出します。
4. ストアが決めた拡張機能の ID を、`crates/vault-client/src/bridge.rs` の `STORE_EXTENSION_IDS` に追加して、アプリの新しい版を出します。それまでは、利用者が設定画面で ID を指定すれば使えます。

| 項目 | 記入例 |
|---|---|
| 単一用途の説明 | 2password デスクトップアプリに保存したログイン情報を、ウェブサイトのログイン画面に入力し、新しいログイン情報をアプリに保存する。 |
| `nativeMessaging` の理由 | 同じパソコンで動く 2password デスクトップアプリと通信し、保存済みのログイン情報を取得・保存するため。 |
| `storage` の理由 | ログイン送信後の「保存しますか？」の確認が終わるまで、送信された情報をメモリ上（storage.session）に一時的に保持するため。ディスクには保存しない。 |
| `activeTab` の理由 | ツールバーのボタンを押したときに、表示中のタブのアドレスを確認し、そのサイトのログイン情報を入力するため。 |
| ホスト権限（すべてのサイト）の理由 | 利用者が訪れる任意のサイトのログイン欄を検出し、候補の表示・入力・保存の確認を行うため。 |
| リモートコード | 使用しない。 |
| データの扱い | 認証情報を扱う。利用者のパソコンの外には送信しない。販売・第三者提供・目的外利用はしない。 |
| プライバシーポリシー | [docs/PRIVACY.md](PRIVACY.md) を公開した URL |
