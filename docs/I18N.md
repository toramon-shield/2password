# 表示言語（多言語対応）

2password のデスクトップアプリとブラウザ拡張機能は、次の 15 言語で表示できます。

| 言語 | コード | 言語 | コード | 言語 | コード |
|---|---|---|---|---|---|
| 日本語 | `ja` | Deutsch | `de` | ไทย | `th` |
| English | `en` | Русский | `ru` | Tiếng Việt | `vi` |
| 简体中文 | `zh` | Türkçe | `tr` | Bahasa Melayu | `ms` |
| Português | `pt` | العربية（右から左） | `ar` | हिन्दी | `hi` |
| Español | `es` | Français | `fr` | Italiano | `it` |

## 言語の決まり方

| 対象 | 決まり方 |
|---|---|
| デスクトップアプリ | パソコンの表示言語に合わせます。**⚙ 設定 → 表示言語** で変えられます（最初の画面とロック画面にも選択欄があります）。対応していない言語のときは英語で表示します |
| ブラウザ拡張機能 | ブラウザの表示言語に合わせます。対応していない言語のときは英語で表示します |
| Emergency Kit | 保管庫を作ったときの表示言語で書き出します（アプリはアプリの表示言語、`2pw init` はコマンドラインの表示言語） |
| コマンドライン（`2pw`） | 環境変数 `TWOPW_LANG`（例: `TWOPW_LANG=en`）、`LC_ALL`・`LC_MESSAGES`・`LANG`、パソコンの表示言語の順に見て決めます。最初に見つかった指定が対応していない言語なら英語です。メッセージと `--help` の説明を訳します（`Usage:` などの枠は英語のままです） |
| Google ログインの完了ページ | ブラウザの表示言語（`Accept-Language`）に合わせます |

## 翻訳ファイル

| ファイル | 中身 |
|---|---|
| `app/ui/locales/<コード>.json` | アプリの画面。`ui` 節は画面の文言、`rust` 節はアプリ本体（Rust）が返す日本語のメッセージ（原文）と、その訳。コマンドラインと Google ログインの完了ページも `rust` 節を使います（ビルドのときに取り込みます） |
| `extension/_locales/<フォルダ>/messages.json` | 拡張機能（Chrome の形式）。フォルダ名は `zh_CN`、`pt_BR`、`pt_PT` のように Chrome の決まりに従う |

日本語（`ja`）が原本です。英語は、訳すときの参照にも使います。

### 差し込み口

| 場所 | 書き方 | 例 |
|---|---|---|
| アプリの `ui` | `{名前}` | `"{n} バイト"` |
| アプリの `rust` | 原文と同じ `{}`、`{e}`、`{ACCOUNT_FILE}` など | `"他の端末の変更を取り込みました（{n} 件）"` |
| 拡張機能 | `$1`、`$2`、`$3` | `"このページは $1 です。"` |

アプリ本体が返すメッセージは、`rust` 節の原文と照らし合わせて訳します。原文の `{}` の部分に入った値（ファイル名やエラーの内容）は、そのまま訳文に差し込みます。`rust` 節にないメッセージは、日本語のまま表示します。

## 翻訳を直す・言語を足す

1. 翻訳ファイルを直します。新しい言語なら、`en.json` と `extension/_locales/en/messages.json` を写して訳します。
2. 新しい言語は、`app/ui/i18n.js` の `LANGS` と、`scripts/i18n.py` の `LANGS` に足します。右から左に書く言語なら、`i18n.js` の `RTL` にも足します。
3. 検査します。キーの過不足、差し込み口、タグの食い違いを見つけます。

```sh
python scripts/i18n.py check          # すべての言語
python scripts/i18n.py check fr de    # 指定した言語だけ
```

4. 画面で確かめます。言語ごとに主な画面を表示し、キーがそのまま出ていないか、日本語が残っていないか、アプリ本体のメッセージが訳されるかを調べます。

```sh
cd scripts/browser-e2e && npm install
node ui-i18n.cjs                # すべての言語
LANGS=fr,de node ui-i18n.cjs    # 指定した言語だけ
```

### Rust のメッセージを変えたとき

アプリ本体やコマンドラインのメッセージ、`2pw` のコマンドの説明（`///` のコメント）を足したり変えたりしたら、原本の `rust` 節を作り直してから、各言語の訳を足します。コマンドラインの見出し（`"アカウントパスワード: "` など）は、前後の空白も原文にそろえます。

```sh
python scripts/i18n.py sync-rust   # ja.json の rust 節を、いまの Rust のソースに合わせる
python scripts/i18n.py check       # 訳が足りない言語を一覧する
```

> [!NOTE]
> 日本語以外の訳は、AI による翻訳をもとにしています。不自然な訳や誤りを見つけたら、Issue か Pull Request で知らせてください。
